C++17 编写的 Windows 像素赛马小游戏。

A pixel horse-racing minigame for Windows, written in C++17. 

## 构建与运行 / Build & Run

在项目根目录的 PowerShell 中运行，需联网下载 Zig 0.13.0 工具链。

Run in PowerShell from the project root. An internet connection is required to download the Zig 0.13.0 toolchain.

默认构建包含自动测试；仅编译可加 -SkipTests。

The default build runs automated tests. Use -SkipTests to build only.
